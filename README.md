# Stalcraft · калькулятор наград

Интерактивный калькулятор багровых гильз, потасовок и турниров для Stalcraft. Работает в браузере, без сервера и установки.

**Сайт:** https://nyrokume.github.io/stalcraft-shells-calculator/

## Возможности

- Расчёт наград по тирам и режимам (потасовки, турниры, межсезонье)
- Настройка пула потасовок: гильзы, казна, влияние, батареи, материалы
- Графики при разной доле клана и сравнение «было → сейчас»
- Автосохранение настроек потасовок в браузере

## Структура

```
index.html                      — входная страница
calculator/shells-charts.html   — калькулятор
calculator/resources-flow.html  — редирект на калькулятор
```

## Локальный запуск

Откройте `index.html` в браузере или поднимите любой статический сервер в корне репозитория.

## Деплой

Сайт публикуется через GitHub Pages из ветки `main`.
